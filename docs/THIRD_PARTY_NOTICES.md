# Внешние визуальные ресурсы

Web-интерфейс загружает шрифты Manrope и Unbounded через Google Fonts во время работы браузера. Соответствующие каталоги Google Fonts указывают SIL Open Font License 1.1:

| Семейство | Лицензия и источник |
| --- | --- |
| Manrope | [OFL.txt](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt) |
| Unbounded | [OFL.txt](https://github.com/google/fonts/blob/main/ofl/unbounded/OFL.txt) |

SVG-макеты в docs/assets созданы для демонстрации интерфейса и используют вымышленные данные.
